Authentication

  • Complete authentication platform + Authenticator with redundancy models (VM or Appliance).

    VPN authentication - SSL VPN (fortinet client - windows / mac / linux).

    MFA with fortinet's own token + MFA at Windows logon.

    Integration with MICROSOFT's AD, with automatic synchronization rules for user groups.

    Automatic allocation of tokens to configured AD groups.

    PEAP, TTLS, TLS, digital certificate per user, 802.1x authentication, LDAP-S, LDAP, Join in AD group.

    Integration with RADIUS, MIST JUNIPER + Integration with SINGLE SIGN ON + External LDAP Bases, etc.

    If the user is locked in AD or has an expired password, it allows you to perform a remote password reset.

    User login tracking + Lock by period of activity.

    Graphical administration that facilitates troubleshooting.

    Token concentration (centralization of MFA in the forti authenticator).

    Authentication of network equipment, centralized in the authenticator.
