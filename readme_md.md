# NGX Cibersegurança - Site Institucional (EN/PT)

Site institucional desenvolvido para a **NGX**, uma empresa especializada em cibersegurança. O principal desafio e diferencial deste projeto foi a imersão profunda na área de atuação do cliente, traduzindo conceitos técnicos complexos em uma comunicação clara, acessível e altamente eficiente para o público-alvo. 

O projeto conta com suporte multilíngue (Inglês/Português) para abranger um mercado global.

---

## 🚀 Tecnologias Utilizadas

O site foi construído utilizando tecnologias modernas e frameworks focados em agilidade e responsividade:

* **Backend:** PHP
* **Frontend:** HTML5, CSS3, JavaScript
* **Framework CSS:** Bootstrap (garantindo um design responsivo e adaptável a qualquer dispositivo)
* **Internacionalização:** Suporte a múltiplos idiomas (EN/PT)
* **Servidor Web:** Apache

---

## 🛡️ Destaques do Projeto

* **Tradução de Conteúdo Técnico:** Transformação de especificações complexas de cibersegurança em uma linguagem de fácil compreensão comercial.
* **Multilíngue (EN/PT):** Estrutura preparada para alternância de idiomas, expandindo o alcance da empresa para clientes internacionais.
* **Design Responsivo:** Layout totalmente adaptado para mobile, tablet e desktop utilizando Bootstrap.

---

## ⚙️ Pré-requisitos

Para rodar este projeto localmente, você precisará de:

* Um servidor local configurado com PHP e Apache (como **XAMPP**, **WampServer** ou **MAMP**).
* PHP (versão 7.4 ou superior recomendada).

---

## 🔧 Como Executar o Projeto

1. **Clone ou baixe** os arquivos do repositório.
2. **Mova a pasta do projeto** para o diretório raiz do seu servidor Apache:
   * No *XAMPP*, por exemplo: `C:/xampp/htdocs/ngxciberseguranca-site/`
3. **Inicie o Apache:**
   * Abra o painel de controle do seu servidor local e clique em **Start** no serviço **Apache**.
4. **Acesse no navegador:**
   * Abra a sua barra de endereços e digite:
     ```text
     http://localhost/ngxciberseguranca-site/
     ```
