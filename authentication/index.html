Authentication

  • Plataforma completa de autenticação + Authenticator com modelos de redundancia (VM ou Appliance).

    Autentição de VPN - SSL VPN (cliente fortinet - windows / mac / linux).

    MFA com token da própria fortinet + MFA no logon do Windows.

    Integração com AD da MICROSOFT, com regras de sincronização automática para grupos de usuários.

    Alocação de tokens de forma automática para grupos de AD configurados.

    PEAP, TTLS, TLS, certificado digital por usuário, autenticação 802.1x, LDAP-S, LDAP, Join no grupo do AD.

    Integração com RADIUS, MIST JUNIPER + Integração com SINGLE SIGN ON + Bases externas de LDAP, etc.

    Se usuário tiver bloqueado no AD ou com senha expirada, permite realizar o reset remoto de senha.

    Rastreamento de login dos usuários + Bloqueio por período de atividade.

    Administração Grafica que facilita o troubleshooting

    Concentração de token (centralização de MFA no forti authenticator).

    Autenticação de equipamentos de rede, centralizados no authenticator.
